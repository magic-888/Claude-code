⚙️ Firebase Setup Required

This app needs a free Firebase Realtime Database to sync locations in real time.

  1. Go to console.firebase.google.com
  2. Create a project → Add a Web App
  3. Enable Realtime Database (test mode)
  4. Copy your config into the FIREBASE_CONFIG block in this file

Then reload the page.
